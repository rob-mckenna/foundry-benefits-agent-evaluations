Lab overview

Read first - 5 min

This lab builds a small, purpose-built evaluation framework for a health plan benefits assistant. It demonstrates one point: an AI answer can be grounded, fluent, and still factually wrong for the member - and a domain-specific evaluation framework on Microsoft Foundry catches it before release.

What you will build

LayerWhat you buildDemo role
Knowledge10 fictional benefit records (Contoso Gold PPO 2026) in Azure AI SearchRetrieval source with deliberate near-neighbors
AgentFoundry prompt agent benefits-agent v1 (baseline) and v2 (regressed)System under test
Gold dataset20 SME-style scenarios with expected service, coverage, and costGround truth
Evaluators4 built-in + 3 custom code-based evaluatorsPart A vs. Part B story
GatePython gate script + GitHub Actions workflow + branch protectionRelease governance
ObservabilityApplication Insights tracingLatency, tokens, trace drill-down

The three-stage story

1Baseline

v1 answers speech therapy questions correctly. All gates pass.

2Regression

v2 adds a "terminology normalization" prompt change. Speech therapy answers now use voice therapy's $60 / 10-visit facts. Groundedness still looks fine.

3Governance

Custom domain evaluators fail on critical rows. The gate blocks promotion; the failure becomes a permanent regression case.

Timing
Build time is about 3-4 hours the first time. Run the evaluations ahead of time; a 20-row run takes a few minutes, so on the day you show finished results and optionally start one live run.
Before you start
This lab uses preview capabilities (custom evaluators, the GitHub evaluation action). Portal menu names and SDK parameters can change; check the References section for the current documentation.
Synthetic data only
Every benefit record and scenario in this lab is fictional. Do not load real member data, PHI, or proprietary plan documents into a lab environment.

Build the Azure AI Search index

20 min

Use the portal wizard so the index gets integrated vectorization and semantic ranking with no code.

Run the import wizard

  1. Azure portal > your Azure AI Search service > Import data (new).
  2. Data source: Azure Blob Storage, container benefits-docs; authenticate with the search service managed identity.
  3. Scenario: RAG. Vectorize text with your Foundry embedding deployment.
  4. Enable semantic ranker.
  5. Object name prefix: benefits-docs. Note the generated index name (this lab calls it benefits-idx).
  6. Create, then wait for the indexer to finish (10 documents).

Verify retrieval

Search explorer > query speech therapy copay. Confirm BEN-ST-001 ranks first and BEN-VT-002 appears lower. That near-neighbor proximity is the risk you will demonstrate.

Connect Search to the Foundry project

Foundry portal > your project > Management center (or project settings) > Connected resources > New connection > Azure AI Search. Prefer Microsoft Entra ID authentication.

Agent instructions - v1 (baseline)
You are the Contoso Health benefits assistant for the
Contoso Gold PPO 2026 plan (fictional demo data).

Rules:
1. Answer ONLY from benefit records returned by the Azure AI Search tool.
2. Always name the exact service you matched and its Record ID.
3. Always state the coverage status: covered, not covered, or prior authorization required.
4. Always give the member cost (copay, coinsurance, deductible) and any visit limits.
5. Never substitute a similar-sounding service. Speech therapy and voice therapy are
   different benefits with different costs.
6. If the question is ambiguous (for example "therapy"), ask which service the member means.
7. If no record matches, say you can't find that benefit and refer the member to Member Services.

Smoke-test in the playground

Ask: Is speech therapy covered under my plan, and what will I pay?

Expected: names speech therapy (BEN-ST-001), covered, $35 copay, 20 visits, prior authorization after the 12th visit.

Turn on tracing

Project > Tracing (Observability) > connect Application Insights if it isn't already. Rerun the question, then open the trace: you should see the search tool call, retrieved chunks, model latency, and token counts.

Register the custom domain evaluators

25 min

Three deterministic code-based evaluators. Each is a Python grade(sample, item) function that returns 0.0-1.0 and runs in a sandbox with no network access.

Service match - near-neighbor detection

eval/evaluators/service_match.py
def grade(sample: dict, item: dict) -> float:
    """Service match: the answer names the expected service and contains
    no facts that belong only to its near-neighbor service."""
    try:
        resp = (item.get("response") or (item.get("sample") or {}).get("output_text") or "").lower()
        expected = (item.get("expected_service") or "").lower()
        forbidden = [t.strip().lower() for t in (item.get("forbidden_terms") or "").split("|") if t.strip()]
        if not resp:
            return 0.0
        if expected and expected not in ("therapy", "hippotherapy") and expected not in resp:
            return 0.0
        if any(f in resp for f in forbidden):
            return 0.0
        return 1.0
    except Exception:
        return 0.0

Cost and limit accuracy

eval/evaluators/cost_accuracy.py
def grade(sample: dict, item: dict) -> float:
    """Cost accuracy: share of required cost/limit facts present in the answer."""
    try:
        resp = (item.get("response") or (item.get("sample") or {}).get("output_text") or "").lower()
        terms = [t.strip().lower() for t in (item.get("expected_cost_terms") or "").split("|") if t.strip()]
        if not terms:
            return 1.0          # nothing to check for this scenario
        if not resp:
            return 0.0
        return sum(1 for t in terms if t in resp) / len(terms)
    except Exception:
        return 0.0

Coverage status

eval/evaluators/coverage_status.py
def grade(sample: dict, item: dict) -> float:
    """Coverage status: covered / not covered / prior authorization / clarify / unknown."""
    try:
        resp = (item.get("response") or (item.get("sample") or {}).get("output_text") or "").lower()
        exp = (item.get("expected_coverage") or "").lower()
        neg = any(k in resp for k in ("not covered", "isn't covered", "is not covered", "excluded"))
        pa = any(k in resp for k in ("prior authorization", "prior auth", "preauthorization", "pre-approval"))
        if exp == "covered":
            return 1.0 if ("covered" in resp and not neg) else 0.0
        if exp == "not covered":
            return 1.0 if neg else 0.0
        if exp == "prior authorization":
            return 1.0 if (pa and not neg) else 0.0
        if exp == "clarify":
            return 1.0 if ("?" in resp or "which" in resp) else 0.0
        if exp == "unknown":
            return 1.0 if any(k in resp for k in ("can't find", "cannot find", "couldn't find", "not listed",
                                                   "no record", "member services")) else 0.0
        return 0.0
    except Exception:
        return 0.0

Register them in the evaluator catalog

eval/register_evaluators.py
"""Register the three benefits domain code-based evaluators in the
Foundry evaluator catalog. Run once per project (bump the version to update)."""
import os
from pathlib import Path
from azure.identity import DefaultAzureCredential
from azure.ai.projects import AIProjectClient
from azure.ai.projects.models import EvaluatorCategory, EvaluatorDefinitionType

project = AIProjectClient(endpoint=os.environ["AZURE_AI_PROJECT_ENDPOINT"],
                          credential=DefaultAzureCredential())

EVALUATORS = {
    "benefits_service_match":  ("Benefits - Service match (near-neighbor)", "evaluators/service_match.py"),
    "benefits_cost_accuracy":  ("Benefits - Cost and limit accuracy",       "evaluators/cost_accuracy.py"),
    "benefits_coverage_status":("Benefits - Coverage status",               "evaluators/coverage_status.py"),
}
FIELDS = ["response", "expected_service", "expected_coverage",
          "expected_cost_terms", "forbidden_terms"]

for name, (display, path) in EVALUATORS.items():
    ev = project.evaluators.create_version(
        name=name,
        evaluator_version={
            "name": name,
            "display_name": display,
            "categories": [EvaluatorCategory.QUALITY],
            "description": f"Benefits evaluation lab - {display}",
            "definition": {
                "type": EvaluatorDefinitionType.CODE,
                "code_text": Path(path).read_text(encoding="utf-8"),
                "init_parameters": {
                    "type": "object",
                    "properties": {"deployment_name": {"type": "string"},
                                   "pass_threshold": {"type": "number"}},
                    "required": ["deployment_name", "pass_threshold"],
                },
                "data_schema": {
                    "type": "object",
                    "properties": {f: {"type": "string"} for f in FIELDS},
                    "required": ["response"],
                },
                "metrics": {"result": {"type": "continuous", "desirable_direction": "increase",
                                       "min_value": 0.0, "max_value": 1.0}},
            },
        },
    )
    print(f"Registered {ev.name} v{ev.version}")

from azure.identity import DefaultAzureCredential

from azure.ai.projects.models import TestingCriterionAzureAIEvaluator
from openai.types.eval_create_params import DataSourceConfigCustom

ap = argparse.ArgumentParser()
ap.add_argument("--agent", default=os.environ.get("AGENT_NAME", "benefits-agent"))
ap.add_argument("--agent-version", required=True)
ap.add_argument("--eval-id", default=os.environ.get("BENEFITS_EVAL_ID") or None)
ap.add_argument("--dataset-version", default=os.environ.get("DATASET_VERSION", "1"))
ap.add_argument("--gate", action="store_true")
a = ap.parse_args()

judge = os.environ["AZURE_AI_MODEL_DEPLOYMENT_NAME"]
project = AIProjectClient(endpoint=os.environ["AZURE_AI_PROJECT_ENDPOINT"],
                          credential=DefaultAzureCredential())
client = project.get_openai_client()
dataset = project.datasets.get(name="benefits-gold", version=a.dataset_version)

FIELDS = ["scenario_id", "query", "expected_service", "expected_coverage",
          "expected_cost_terms", "forbidden_terms", "ground_truth", "slice", "severity"]
DOMAIN_MAP = {"response": "{{sample.output_text}}",
          **{f: "{{item.%s}}" % f for f in FIELDS if f.startswith(("expected", "forbidden"))}}

def crit(name, evaluator, mapping, extra=None):
    params = {"deployment_name": judge, **(extra or {})}
    return TestingCriterionAzureAIEvaluator(type="azure_ai_evaluator", name=name,
                                            evaluator_name=evaluator,
                                            initialization_parameters=params,
                                            data_mapping=mapping)

testing_criteria = [
    # ---- Microsoft built-in evaluators (Part A of the demo) ----
    crit("groundedness", "builtin.groundedness",
         {"query": "{{item.query}}", "response": "{{sample.output_items}}"}),
    crit("relevance", "builtin.relevance",
         {"query": "{{item.query}}", "response": "{{sample.output_text}}"}),
    crit("response_completeness", "builtin.response_completeness",
         {"response": "{{sample.output_text}}", "ground_truth": "{{item.ground_truth}}"}),
    crit("task_adherence", "builtin.task_adherence",
         {"query": "{{item.query}}", "response": "{{sample.output_items}}"}),
    # ---- Domain-specific custom evaluators (Part B of the demo) ----
    crit("benefits_service_match",   "benefits_service_match",   DOMAIN_MAP, {"pass_threshold": 1.0}),
    crit("benefits_cost_accuracy",   "benefits_cost_accuracy",   DOMAIN_MAP, {"pass_threshold": 1.0}),
    crit("benefits_coverage_status", "benefits_coverage_status", DOMAIN_MAP, {"pass_threshold": 1.0}),
]

eval_id = a.eval_id
if not eval_id:
    ev = client.evals.create(
        name="Benefits agent - domain evaluation",
        data_source_config=DataSourceConfigCustom(
            type="custom",
            item_schema={"type": "object",
                         "properties": {f: {"type": "string"} for f in FIELDS},
                         "required": ["query"]},
            include_sample_schema=True),
        testing_criteria=testing_criteria)
    eval_id = ev.id
    print(f"Created eval {eval_id}  (reuse it with --eval-id so runs can be compared)")

run = client.evals.runs.create(
    eval_id=eval_id,
    name=f"{a.agent}-v{a.agent_version}",
    data_source={
        "type": "azure_ai_target_completions",
        "source": {"type": "file_id", "id": dataset.id},
        "input_messages": {"type": "template", "template": [
            {"type": "message", "role": "user",
             "content": {"type": "input_text", "text": "{{item.query}}"}}]},
        "target": {"type": "azure_ai_agent", "name": a.agent, "version": a.agent_version},
    })
print(f"Run {run.id} started for {a.agent} v{a.agent_version}")

while True:
    run = client.evals.runs.retrieve(run_id=run.id, eval_id=eval_id)
    if run.status in ("completed", "failed", "canceled"):
        break
    time.sleep(10)
print(f"Status: {run.status}\nReport: {run.report_url}")
if run.status != "completed":
    sys.exit(2)

# ------------------------- release gate -------------------------
def g(o, k, d=None):
    return o.get(k, d) if isinstance(o, dict) else getattr(o, k, d)

DOMAIN = {"benefits_service_match", "benefits_cost_accuracy", "benefits_coverage_status"}
POOLED = {"groundedness": 0.90, "relevance": 0.90}
pooled = {k: [0, 0] for k in POOLED}
blocking = []
for it in client.evals.runs.output_items.list(run_id=run.id, eval_id=eval_id):
    row = g(it, "datasource_item", {}) or {}
    for r in g(it, "results", []) or []:
        name, passed = g(r, "name"), bool(g(r, "passed"))
        if name in DOMAIN and row.get("severity") == "critical" and not passed:
            blocking.append(f"{row.get('scenario_id')} [{row.get('slice')}] {name}: {row.get('query')}")
        if name in pooled:
            pooled[name][0] += passed
            pooled[name][1] += 1

print("\n=== Release gate ===")
for k, (p, n) in pooled.items():
    rate = p / n if n else 0
    flag = "OK " if rate >= POOLED[k] else "LOW"
    print(f"{flag} {k:<14} pass rate {rate:.0%} (threshold {POOLED[k]:.0%})")
    if rate < POOLED[k]:
        blocking.append(f"{k} pass rate {rate:.0%} below {POOLED[k]:.0%}")
if blocking:
    print("\nBLOCKED - release-blocking failures:")
    for b in blocking:
        print("  -", b)
    sys.exit(1 if a.gate else 0)
print("\nPASSED - candidate may be promoted")

Add the workflow

.github/workflows/benefits-eval-gate.yml
name: benefits-eval-gate
on:
  workflow_dispatch:
    inputs:
      agent_version:
        description: "Candidate agent version to evaluate"
        required: true
  pull_request:
    paths: ["agent/**", "eval/**"]

permissions:
  id-token: write
  contents: read

jobs:
  evaluate:
    runs-on: ubuntu-latest
    environment: eval-demo
    env:
      AZURE_AI_PROJECT_ENDPOINT: ${{ vars.AZURE_AI_PROJECT_ENDPOINT }}
      AZURE_AI_MODEL_DEPLOYMENT_NAME: ${{ vars.JUDGE_DEPLOYMENT }}
      AGENT_NAME: benefits-agent
      BENEFITS_EVAL_ID: ${{ vars.BENEFITS_EVAL_ID }}
    steps:
      - uses: actions/checkout@v4
      - uses: azure/login@v2
        with:
          client-id: ${{ vars.AZURE_CLIENT_ID }}
          tenant-id: ${{ vars.AZURE_TENANT_ID }}
          subscription-id: ${{ vars.AZURE_SUBSCRIPTION_ID }}
      - uses: actions/setup-python@v5
        with:
          python-version: "3.11"
      - run: pip install -r eval/requirements.txt
      - name: Benefits evaluation release gate
        run: python eval/run_eval.py --agent-version "${{ inputs.agent_version || vars.CANDIDATE_VERSION }}" --gate
